# Smart Campus Placement Management System

## 📌 Project Overview

Smart Campus Placement Management is a ServiceNow-based application designed to digitize and simplify the campus placement process.

The system manages students, companies, job openings, applications, interviews, offers, email notifications, and placement analytics through a centralized platform.

## 🎯 Objectives

- Manage student placement information
- Maintain company and job opening details
- Manage student applications
- Track application status
- Schedule interviews
- Manage placement offers
- Send automated email notifications
- Provide placement analytics through dashboards
- Improve transparency and efficiency in the placement process

## 🧩 Modules

## 🛡️ Business Rules

The application validates required dates:

- Applied Date is required for every application
- Interview Date is required
- Offer Date is required

## 📊 Dashboard

- Total Applications

- Total Interviews
- Total Offers
